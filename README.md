## 格式

每期分别保存为 `reports/YYYY/MM/YYYY-MM-DD.md` 和同名 `.json`。

Markdown 用于直接阅读或在本地笔记工具中打开；JSON 保留结构化字段，便于本地模型或其他阅读界面继续处理。归档不自动表示结论已采用，也不表示论文或代码已复现。

## 证据原则

1. 区分来源发布日期、修订日期与本次核查日期。
2. 优先使用论文、官方代码与官方发布说明，保留版本明确的链接。
3. 分开事实摘要、工程建议和未知项；实验建议不等于实际实验结果。
4. 首期可收录明确标注的历史基线；后续不以旧消息冒充新进展，不为数量凑条目。
5. 不存放私人知识库内容、聊天记录、收藏信息、身份凭据或受版权保护的原文全文。
6. 同日重复执行先核对已有文件；一致内容不重复提交，实质更正明确说明并保留 Git 历史。

本仓库只保存可公开的日报资料。个人阅读网站的收藏与访问权限不由本仓库管理。

## 大模型前沿用法

新增重点追踪 GPT/OpenAI、Claude/Anthropic 等生态的实质新用法：新使用机制、工具能力和可落地实践。Skill、工作流、多智能体只是技术演变的例子，不重复基础概念，也不预设它们已过时。每条说明相对旧方法的新变化、发布日期、可用状态、入口、限制与最小试用步骤。官方发布、演示、独立实测分别标注；社区帖子用于发现线索，重要事实回溯原始来源。无合格新进展时明确无新增，不以旧闻凑数。
