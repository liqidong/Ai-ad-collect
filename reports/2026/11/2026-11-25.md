算法研究日报 · 11 月 25 日（上海）
三项各自解决一个落地瓶颈：直播高斯的传输、外部 PDF 解析的来源坐标、CLI 恢复的执行边界。它们分别是论文、已合并补丁、正式 CLI 版本。

## 数字人 / 几何｜HoloSplat：实时自由视角人像传中间特征，而不是传完整高斯

- 日期/状态：arXiv v1 2026-11-23 18:11:00 UTC；11月24日列入cs.CV。 / 11月24日arXiv列表发现 / 论文公开
- 已知事实：八路标定真人视频的服务器把高斯预测头之前的中间特征分帧压缩，客户端解码 3DGS。作者五张 5090 的 Wi-Fi 实验平均端到端 204–304 ms。
- 工程意义：可作为多机位真人体积直播的系统设计参考，不是可驱动人物资产或已可安装的工具。
- 最小验证：先借用延迟和码率验收设计，分别看首帧、捕获到显示延迟及可用帧率；未开放前不按单卡性能排期。
- 限制/未知：作者多卡实验；代码待发布，权重未确认。

## 知识库 / RAG｜RAGFlow 原生导入 Docling JSON：保留阅读顺序、标题与页坐标

- 日期/状态：2026-11-24T11:06:43Z 合并；11月25日上海核查。 / 11月24日主分支合并 / 未独立运行
- 已知事实：RAGFlow #22728 能将 Docling JSON 的正文按树序读成段落与标题，并把原页号和有效坐标带进 General 切块。
- 工程意义：可先在外部做文档解析，再把结构化正文送去知识库，不必把整份 JSON 当成无结构文本。

- 限制/未知：只覆盖首批正文与标题；已合并主分支，未确认随稳定版交付，无独立召回实测。

## 大模型前沿用法｜Codex 0.172.0：恢复 CLI 任务时保留原工作目录与权限
