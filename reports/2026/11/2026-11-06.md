## CrossPressor：压缩多视角融合开销，注意整体加速远小于局部加速

类别：数字人 / 几何

来源日期：2026-11-04 10:07 UTC 提交，11月5日 arXiv 公布

**事实：** 新论文在已有 ZPressor 锚点式多视图重建中，保留完整锚点查询，仅对支持视角特征进行跨视角、跨层轮换采样，并在 K/V 投影前打包；复用已有权重，无须重新训练。

**相关性：** 适合研究大量相机输入时的特征融合瓶颈，不是人脸几何或可驱动表示的新方案。

**建议：** 先测现有流程融合占总耗时比例；代码发布后，在相同权重与数据上比较融合时间、端到端时间、总显存及保留视角细节。

**限制与未知：** 仅静态场景实测；256视角下局部26.12倍不等于整体26倍，总体为1.43倍；融合显存下降但模型峰值显存基本不变。官方仓库尚为占位，未复现。

## LangGraph 1.2.20：过期审批显式失败，连续中断使用不同身份

类别：智能体 / 应用

来源日期：核心1.2.20：2026-11-05 02:20 UTC；SDK PR：2026-11-05 16:15 UTC 合并

**事实：** 11月5日发布的核心1.2.20加入严格恢复校验与独立中断身份：可让过期、空或有歧义的恢复请求显式失败，避免旧审批误答同一节点的下一问。

**相关性：** 长期 Agent 人工审批需要处理重复点击、延迟回复和节点重试；中断身份校验能缩小错误恢复范围，但不能替代权限或幂等控制。

**建议：** 在隔离图中用内存或 SQLite 检查连续两问：开启实验性严格配置，重复提交第一问 ID 应报错并保持第二问等待；再验证当前 ID。勿对真实副作用测试。

**限制与未知：** 严格模式默认关闭，核心1.2.20仅为私有配置键；Python SDK 参数11月5日后续合并，但当日发布的0.4.13不含该参数，远端还需服务端声明支持；未运行测试。

## RAGFlow：过滤无来源检索块，并保留合法数据集编译结果

类别：知识库 / RAG

来源日期：2026-11-05 02:43 UTC 合并

**事实：** 11月5日合入主分支的修复在检索打分前过滤无字段、缺少有效文档 ID 或源文档已不存在的普通块，保留满足严格条件的数据集编译块和原始引擎字段。

**相关性：** 用于降低已删文档残留块进入下游生成的风险；属于结果一致性修复，不是新检索算法或权限校验。

**建议：** 在隔离测试中混合有效块、孤儿块、空文档 ID 和合法编译块，检查返回顺序、原始字段和空结果，再确认部署版本是否包含提交。

**限制与未知：** 已合主分支，未确认稳定发行包或镜像包含；测试用内存 SQLite 与模拟检索引擎，未验证生产并发，也没有召回率或问答质量结论。
