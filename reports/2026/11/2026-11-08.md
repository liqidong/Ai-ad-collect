## EDGAR 公开合成修复训练子集，作者权重仍受限

分类：数字人 / 几何

来源日期：v1.0 资产原发布时间：2026-11-05 04:12:47 UTC；数据说明更新：2026-11-07 03:23:34 UTC；代码下载说明更新：03:24:21 UTC。精确转公开时刻未证实。

开放状态：官方公开下载说明11月7日更新；合成数据可公开获取，完整推理仍受限

**来源事实**：11月7日官方文档将 CAFCA-only 从私有改为公开下载，包含1,500个合成身份、22,420个参考图／目标图／退化渲染三联样本。公开 API 已列出11个 TAR、元数据 ZIP 和校验文件；v1.0 资产原发布时间为11月5日，并非11月7日新上传。

**工程意义与建议**：降低头像渲染修复研究的数据获取门槛。公开训练入口允许从 SD-Turbo 初始化新模型，不必先取得私有 EDGAR checkpoint；这不是已训练模型开放。 先核对非商业许可、全部分片校验与身份不交叉切分，再做少量训练更新、保存恢复和真实留出身份测试。详解区分三联图顺序、依赖及完整复现缺口。

**限制与未知**：Both 混合数据和作者六专家权重仍私有，无 CAFCA-only 预训练 checkpoint。数据 CC BY-NC-SA 4.0；本轮未下载大资产或运行训练。数据不是三维几何真值，不能直接修正结构、导出 Mesh 或保证连续帧稳定。

## Codex 预发布版：工作区可写不再隐含信任项目 MCP 配置

分类：大模型前沿用法

来源日期：PR #60041：2026-11-07 02:39:18 UTC 合并；0.169.0-alpha.3：2026-11-07 19:31:41 UTC 发布。

开放状态：11月7日合并并进入预发布版；源码核验，未独立实测

**来源事实**：11月7日合并的修复将非交互执行的工作目录传递与项目信任分开，避免仅指定 workspace-write 就启用未授信项目配置；新增 --trust 明确保存授信。已核进入 0.169.0-alpha.3，不能当作稳定版 0.167 的能力。

**工程意义与建议**：适合 CI、自动审查和定时编码任务，防止文件写权限被误当成允许仓库配置启动宿主进程。这与昨日失败响应 token 计数修复是独立增量。 在隔离 CODEX_HOME、自建测试仓库与模拟 MCP 服务中验证默认禁用、显式授信、跨次持久和拒绝优先。不要为跑通流水线对不可信仓库统一添加 --trust。

**限制与未知**：仅确认预发布源码与资产，未安装或独立运行。--trust 即使搭配 --ephemeral 仍持久，MCP 命令可能在沙箱外运行；不涵盖所有 app-server 授信路径，合并点公开 CI 非全绿。

## MinerU 收紧 URL 入库：先验证全部 DNS 结果，再固定公网连接

分类：采集 / 工具

来源日期：初始 URL 防护提交：2026-11-06 10:37:27 UTC；PR #5730 于2026-11-07 08:44:53 UTC 合入 dev。

开放状态：11月7日进入开发分支；稳定包尚未确认包含

**来源事实**：11月7日合入 dev 的修复在连接前验证全部 DNS 地址，再固定连接已验证公网 IP，同时保留 Host/SNI 和签名路径、隔离环境代理，减少文档 URL 下载入口的 SSRF 风险。

**工程意义与建议**：适用于面向用户开放 URL 入库的知识库服务，保护下载入口；不提升文档解析准确率、检索召回或模型能力。 固定合并提交，在隔离环境用模拟 DNS/HTTP 回归验证混合地址零连接、候选回退、代理与 TLS 边界，并检查部署是否依赖企业代理或 Fake-IP DNS。

**限制与未知**：最新正式版仍为11月4日的4.1.7；只确认开发分支、测试源码及作者 CI，本轮未运行测试或确认线上部署。旧客户端原本默认不跟随重定向，本次只是显式固定，不冒充新能力。
