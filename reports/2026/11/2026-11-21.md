# 流式语音人像、远程 Codex 执行与幻灯片媒体溯源

三项深读：Kyutai AURA 的语音驱动2D人像、Codex 0.171.0 的非交互远端执行、Docling 的幻灯片音视频定位与转写。各项区分可安装发行、主分支合并和作者测量。

未运行模型、付费API或远端服务，也未下载大权重。来源中不同分辨率及测试口径单列；所列对照为建议，不是实际复现。

## 数字人 / 几何：Kyutai AURA：单卡流式语音驱动人像视频，先分清生成吞吐与交互延迟

- 时点：论文v1 2026-11-19；官方博客 2026-11-20；GitHub推理提交 2026-11-20T14:16:12Z；两模型卡当日14:13 UTC更新，创建时间不等同公开时间。
- 事实：Kyutai公开语音驱动2D人像视频的推理代码与两档权重。1.3B在单H100的优化链路报告20.7 fps，公开参考代码约16 fps。
- 工程意义：可作为现有3D数字人的2D口型与端到端延迟非商业研究对照。
- 建议：先明确非商业许可和输入链路；验证中文口型、首帧延迟与漂移，不需要重建3D资产。
- 未知或限制：两档权重及主体代码非商用；公开CLI先处理音频文件；不是3D资产，未实测本地。

## 智能体 / 应用：Codex 0.171.0：非交互 CLI 可连接既有 app server

- 时点：发行 2026-11-20T00:44:47Z；2026-11-21 上海核查。
- 事实：0.171.0 正式交付 `codex exec --remote <ADDR>`；脚本可使用服务端配置新开任务或按 UUID 接力，取得 JSONL 或文本。
- 工程意义：为不同调用方接入同一个受控 Codex app server 提供更薄的接口，不是跨框架任务调度器。
- 建议：有受控既有服务时，从临时只读任务验证新开、续接、完成事件和状态核对。
- 未知或限制：只支持有限参数；活动线程拒绝，断流不是回滚；不用于依赖现场人工审核的执行。未实跑。

## 采集 / 工具：Docling：PPTX/ODP 内嵌音视频可保留为轨道并转写

- 时点：合并 2026-11-20T19:09:46Z；2026-11-21（上海）核查。
- 事实：合并版将 PPTX/ODP 内嵌音视频保留为轨道；显式 --convert-media 可转写并提取视频帧，保留幻灯片与媒体时间戳的双重溯源。
- 工程意义：带讲解的课件和报告可纳入文档检索，并引用到哪页、哪一段讲话；与昨日页面视觉解析不同。
- 建议：先用合成演示文稿验证转写、页码和媒体时间戳；按是否需要归档素材决定是否启用 keep_media。
- 未知或限制：已合入主分支，未核到包含改动的正式发行；旧容器或未授权链接可能仅保留引用/封面，未独立运行。
