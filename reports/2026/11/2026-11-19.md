## 智能体 / 应用：Codex 中断恢复：先持久化已接收的子代理回复，再发终止事件

时点：合并2026-11-18T19:40:16Z；2026-11-19核查。

事实：修复父回合中断时已接收但未消费的子代理回复可能丢失：终止通知前先保存消息历史。

工程意义：多代理取消恢复中的消息可靠性，区别于输出项边界中断与任务副作用幂等。

建议：为“收到子回复后立即中断父回合”建立回归，分别验收持久历史和下一请求里的消息计数。

未知与限制：主分支修复，最新稳定版发布早于该提交；仅Mock回归，未独立运行。

## 知识库 / RAG：LightRAG：回答模型故障不再伪装成知识库没找到

时点：2026-11-18T12:55:01Z 合并；2026-11-19（上海）核查。

事实：PR #4478 移除 aquery_llm 吞错：回答模型超时不再变成空知识库；库抛异常，所核 HTTP 路由在未开始响应时返回脱敏 500，已打开的进度流用 error 行。

工程意义：把空证据率和基础设施故障率分开，避免错误触发补数据或重建索引。与早前最终证据判空、重排重试分类是不同层的变化。

建议：先用模拟超时与零证据做契约测试，覆盖库、普通 HTTP 与进度 NDJSON；升级前让客户端显式处理异常和 error 行。

未知与限制：main 已合并，未核到包含此提交的新发行。作者离线用例不等于生产验证，500 并不细分为 504，流式 200 也不代表请求成功。
