# 逐帧高斯网格、可重光照头部与 MCP 技能的执行边界

算法研究日报 · 11 月 27 日（上海）
MEMO 有可查代码和示例模型，可用来核验逐帧网格提取。LuxAvatar 提出高斯约束加视频着色的头部架构。Claude Code 增加 MCP 技能分发，并为另一类本地技能的加载期命令提供独立控制。

仅采用公开一手来源；论文、已发布工程和 beta 分开。本文未安装组件、下载模型或复现实验。

## 数字人 / 几何｜MEMO 发布代码与示例权重：从动态高斯逐帧提取网格

- 日期/状态：2026-11-26 arXiv 列表及公开工程核查 / 新公开论文、作者代码和场景模型
- 事实：作者代码和场景模型已可见：为动态高斯训练显式表面，从每个时刻分别提取网格，并提供不需训练的合成场景样例。
- 工程意义：给动态 Gaussian-to-Mesh 一个可检查的参考实现；与直接对普通高斯 PLY 后处理或输出可动画统一拓扑不同。
- 最小验证：研究用途先提作者样例的几个网格，校验默认与论文模式的边界边、法线和碎片数。
- 局限：完整运行仅核到作者 A100 环境；非商用组件与权重另受许可，逐帧无拓扑对应。

## 数字人 / 几何｜LuxAvatar：用可驱动高斯提供几何和材质，再用因果视频模型重光照

- 日期/状态：arXiv v1 2026-11-25 18:59:46 UTC；11月26日列入cs.CV。 / 11月26日arXiv列表新增 / 论文公开
- 事实：单图建立FLAME绑定的高斯代理，视频模型在指定姿态、相机和照明下补足皮肤及光照细节。
- 工程意义：适合作为头部高斯和视频扩散分工的研究参考；最终产物是视频，不是高精头部Mesh。
- 最小验证：先用既有头模产出法线与底色缓冲，对照检验身份、口型和光照，保留纯高斯渲染备份。
- 局限：论文公开，未确认代码或权重；两卡26 FPS为作者吞吐，不代表互动时延或Mac可运行。

## 大模型前沿用法｜Claude Code：MCP 可以发布技能，加载时的内联命令可单独拦截

- 日期/状态：2026-11-25T01:32Z / 11 月 25 日官方发行 / MCP 技能公开 beta
- 事实：Claude Code 把受支持 MCP 服务的技能列成 server:skill；v2.1.332 另加 PreSkillShellCommand，处理加载阶段的 shell 命令。
- 工程意义：团队集中分发研究技能时，可把技能发布、提示加载和本地执行分开验收。
- 最小验证：先发布纯文档测试技能；再用本地无副作用的内联命令验证阻断，并单独测常规工具调用。
- 局限：限具备资格的直连交互会话；MCP 技能本身不执行内联 shell；旧客户端会忽略新 hook。
