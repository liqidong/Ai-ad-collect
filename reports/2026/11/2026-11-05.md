## Phase-DGS：用运动相位对齐不同步多视角，注意评测使用真实对应

类别：数字人 / 几何

来源日期：2026-11-03 10:51 UTC 提交；11月4日 arXiv 公布

**事实：** 11月4日公布的论文用冻结的 DINOv2 和相位网络估计各帧动作相位，以相位替代时间戳驱动现有动态高斯骨架；面向掉帧、冻结和时间偏移。

**相关性：** 可用于思考多机拍摄时间不同步如何影响动态人物重建；它不是表情驱动头像或静态 Mesh 导出方法。

**建议：** 先在自有采集设计中保留同步参考并统计错位，再等代码开放后比较相同视角、相同时间对齐条件下的重建；不要先假定它能直接解决身份保持。

**限制与未知：** 作者评测使用真实时间对应建立锚点，且以 GT PSNR 搜索相位，基线没有同样先验；结果不等于公平的端到端自动同步。代码标注即将开放，未验证权重或实际运行。

## Claude Message Threads：服务端暂存会话以减少重复上传，但不是长期记忆

类别：大模型前沿用法

来源日期：2026-11-02 官方发布说明；2026-11-05 核查

**事实：** Anthropic 于11月2日公布 Messages API 的 message threads 测试：首次提交完整对话，后续引用上一条响应 ID，只传新增消息，减少重复上传和处理，目标是降低首 token 延迟。

**相关性：** 适合带多轮工具调用的研究或编码 Agent；与自管长期记忆不同，服务端状态短暂且可能丢失。

**建议：** 在 Claude API 测试环境启用 message-threads-2026-08-12 beta：先用 create 发送完整对话，再用上一响应 ID 和 continue 发送新增消息；本地保留完整历史并验证过期后重建。对照测请求字节、首 token 延迟及费用。

**限制与未知：** 测试版支持所有模型及指定平台；空闲5分钟过期，最迟一小时删除；不支持 ZDR/HIPAA，不降低 token 单价或速率限制。每个响应只能继续一次，无法直接分叉；未调用 API 实测。
