## Claude API 2026-10-21：升级 SDK 之前先迁移请求契约和网关鉴权
栏目：大模型前沿用法｜已发布的破坏性接口升级
来源日期：2026-10-21；Python v2.0.0 发布页显示15:51 UTC
来源事实：10月21日发布新 API 版本与 SDK 主版本；采样参数被移除，新客户端默认鉴权头及消息类型也变化。这是兼容性迁移，不是模型能力升级。
工程意义：RAG 与多模型统一封装经常自动附加 temperature 或重写鉴权头，升级可能让原本可用的链路直接失败。
建议：先固定旧依赖；在隔离分支用合成请求核对参数、消息角色、网关头和类型，再小流量迁移。
限制／未知：已发布但未在本轮安装或调用；API 版本兼容与 SDK 本地破坏性变更是两个维度。Bedrock 旧模型另有限制。

## Claude Code v2.1.307：HTTP MCP 断线后不再无差别重试写工具
栏目：智能体 / 应用｜已发布修复；需故障注入验收
来源日期：2026-10-21 22:17 UTC，v2.1.307发布页
来源事实：10月21日发布修复，将调用中断后的自动重试限制到只读或幂等工具，并新增安全干预遥测事件。与上期工作流恢复修复不同，这是单次远程工具调用边界。
工程意义：科研智能体一旦连接任务提交、数据库写入或文件发布，断线后重复执行可能比模型回答错误更昂贵。
建议：在无外部副作用的测试 MCP 服务模拟“服务端已执行、客户端未收到响应”，检查只读、幂等、非幂等三类工具的调用次数。
限制／未知：仅官方发布行为说明；未安装或注入断线实测。不能把修复解释为所有链路的 exactly-once 保证。
