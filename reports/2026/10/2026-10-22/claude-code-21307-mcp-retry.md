# Claude Code v2.1.307：把连接恢复与副作用重放分开

来源日期：2026-10-21 22:17 UTC，v2.1.307发布页
核查时点：2026-10-22T00:08:30Z（UTC）
状态：公开来源研读草稿，未独立复现实验。

## 核心问题
远程工具可能已经执行成功，但响应因连接关闭而丢失。客户端只看见失败，如果直接再发一次，写入、提交任务或发布便可能重复。10月21日的修复针对HTTP MCP调用中途断线；上期v2.1.305针对工作流恢复时重跑已完成子代理，二者不是同一个层级。

## 输入
运行v2.1.307的Claude Code、HTTP MCP服务、工具描述、调用参数及断线事件；不涉及训练。测试应使用本地模拟计数器，不要用真实付款、发信或生产任务提交制造故障。

## 输出
恢复后的工具结果或错误，以及可供排查的遥测记录。需要额外观察服务端实际执行次数和业务状态，因为客户端报错并不能单独证明“没有执行”。

## 分步流程

### 1. 先确定工具实际语义
工程建议：给测试服务准备读取计数、按固定键设置值、追加计数三种工具。输入同一参数重复调用，分别观察是否改变状态、是否产生额外变化，输出独立的行为分类。不要只相信工具名称里写了read或safe。

### 2. 制造结果未知的断线
工程建议：服务端完成状态变化后、返回响应前关闭连接。记录请求ID、业务键、实际状态和调用次数，形成“执行已发生但结果未抵达”的测试样本。这与请求根本没有到达服务器是不同故障点，应分别覆盖。

### 3. 验证新的重试边界
来源事实：v2.1.307发布说明称此类HTTP MCP重试仅对只读或幂等工具进行。工程建议：对三类测试工具分别回放，检查非幂等工具是否没有自动再次执行；如果结果不明，应先读回状态再决定后续操作，而不是把连接恢复当作重做许可。

### 4. 观察安全干预，但不伪造字段
来源事实：同版新增claude_code.safety_event，记录工具调用被权限规则、自动模式、安全检查、hook或沙箱干预的情况。官方监控文档可核验通用OTel配置，但本轮未找到新事件完整schema。工程建议：先用本地console导出和合成操作检查实际事件，不预先编造字段解析器。

### 5. 补齐应用级去重
工程建议：对真实写工具仍使用业务幂等键、状态查询和审计日志。工具侧先查该业务键是否已完成，再执行或返回既有结果；重试次数指标与最终状态同时验收。客户端修复只是降低某类重放风险，不替代应用事务。

## 关键机制
本次新增价值是把传输恢复和业务动作重放分离。只读操作不改变环境，幂等操作在相同参数下重复执行不增加效果；MCP规范中的readOnlyHint/idempotentHint只是描述性提示，不是行为保证，且不应据不可信服务的提示决定安全性。本轮无法核验Claude Code内部究竟如何组合这些提示，因此不宣称已读到重试实现。

## 来源结果与证据

### 官方修复目标是HTTP MCP断线后的重复调用
v2.1.307的发布说明明确限制重试类别；发布日期为10月21日22:17 UTC。没有提供重复调用率、基准数据集或对比表，也没有本轮实测数值。
来源：https://github.com/anthropics/claude-code/releases/tag/v2.1.307

### 安全事件是本版新增能力
同一发布说明列出claude_code.safety_event。监控文档验证日志/事件通过OTEL_LOGS_EXPORTER配置；本次未发现新事件字段表。
来源：https://github.com/anthropics/claude-code/releases/tag/v2.1.307

### 工具声明不是安全证明
MCP ToolAnnotations规范说明提示不保证忠实描述行为；readOnlyHint和idempotentHint默认false。该规范仅解释边界，不被当成本日新技术。
来源：https://modelcontextprotocol.io/specification/2025-06-18/schema#toolannotations

## 工程建议（非复现结论）
- 最低试用：隔离环境确认claude --version，接入无外部副作用的HTTP MCP测试服务；用服务端日志验证三类工具在两个断线时点的实际执行次数。
- 遥测可先采用CLAUDE_CODE_ENABLE_TELEMETRY=1和OTEL_LOGS_EXPORTER=console；这是测试建议，未在本轮开启。正式导出前审核数据和目标，避免把提示词、工具参数或秘密传往未经授权的收集端。
- 建议为每次研究任务提交携带独立业务ID，并提供查询状态工具；失败路径的验收价值可能高于继续加长提示词。
