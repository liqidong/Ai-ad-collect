## OpenAI 调度接口进入 Node 主分支：投递完成不等于任务完成

分类：大模型前沿用法

来源日期：Node提交：2026-10-24T02:39:23Z；Python提交：2026-10-23T21:23:35Z；社区公告：2026-10-23T21:24:34Z

状态：10/24 Node 主分支新增；10/23 API 能力补收

- 来源事实：10月24日 Node SDK 主分支加入 Scheduled Automations API 和 agent 工具，支持定时新建或续接 session。调用链分为 schedule、invocation 投递、session 执行三层，completed 不能混作业务成功。
- 工程意义：适合日报、周期研究和有历史上下文的复查任务。可将到点投递交给托管调度，但应用仍要验收结果、处理权限和保证外部副作用幂等；不是替代工作流编排的新模型能力。
- 建议（未复现）：先以 HTTP beta 接口在无工具的测试 session 安排一次合成文本任务，分别记录创建、投递、主回合结束和结果。另测手动触发与到点触发并存、忙会话、暂停及取消。
- 限制与未知：本期新增是 Node 主分支接口，非正式包发版；API 为10月23日能力补收。最新正式 Node 7.43.0 / Python 3.37.0仍为10月22日。未调用服务；调度幂等、重试与时效不能从生成式客户端测试推出。

## LangGraph 1.2.17：显式循环上限不再被默认值吞掉

分类：智能体 / 应用

来源日期：2026-10-24T00:56:20Z合并；2026-10-24T01:08:05Z发布

状态：10/24 01:08 UTC正式版发布｜真实运行边界修复

- 来源事实：10月24日正式发布1.2.17，修复recursion_limit恰好等于环境默认值时被当作未设置、先前绑定的更高上限继续生效的问题。内部默认值改为私有int子类标记，配置合并按类型而不是数值相等判断。
- 工程意义：适合多轮检索、反思或工具循环型RAG代理的成本与终止边界验收。限制是图的superstep上限，不是token或金额预算；不能据此宣称每次LLM调用都能被单独限额。
- 建议（未复现）：先在隔离测试图对比1.2.16与1.2.17：将环境默认值设为1000，再将原先绑定5000/9999的图显式收紧到1000；同时验证遗漏上限不覆盖子图已绑50、deepcopy/pickle后仍成立。用小上限的无外部调用循环实际验收停止，不拿生产Agent试跑。
- 限制与未知：官方发布及publish流水线已确认，正式发布提交的Python 3.10–3.14核心测试均成功；本轮未安装或运行。LangChain Core自己的merge_configs同类问题仍独立存在，不能把升级LangGraph当作整条调用链已修复。另一项远程子图命名空间修复在10/23已合入，本次只是随正式版可用。
